# 統合CADビューワ 静的ホスティング用パッケージ

このフォルダの中身をそのまま以下のような静的ホスティングサービスにアップロードするだけで公開できます。
サーバー側の処理は一切不要です(すべてブラウザ内で完結します)。

## 対応ファイル形式
- IFC / IFCXML ファイル: 3Dビューワで表示します(階層・断面・計測・配管サイズ表示に対応)
- JWW (Jw_cad) ファイル: 2Dビューワでブラウザ内で直接解析して表示します
- DXF ファイル: 2Dビューワでブラウザ内で直接解析して表示します
- DWG ファイル: 仕様が非公開のため直接は開けません。無料の「ODA File Converter」(Autodesk公式の変換ツール)などでDXF形式に変換してからお使いください

IFCファイルを開くと自動的に3D表示に、DXF/JWWファイルを開くと自動的に2D表示に切り替わります(同一アプリ内でシームレスに切り替わりますが、3D/2Dを同時に重ねて表示することはできません)。

## デプロイ方法の例

### GitHub Pages
1. GitHubで新しいリポジトリを作成する
2. このフォルダの中身(index.html, manifest.json, icon-192.png, icon-512.png)をリポジトリ直下にアップロードする
3. リポジトリの Settings → Pages で公開ブランチ(例: main)とルート(/)を指定して保存する
4. 数分後に https://(ユーザー名).github.io/(リポジトリ名)/ で公開されます

### Cloudflare Pages
1. Cloudflareダッシュボードで Workers & Pages → Pages → 「アップロードして配置」を選ぶ
2. このフォルダをそのままドラッグ&ドロップしてアップロードする
3. 発行されたURL(例: https://xxxx.pages.dev)ですぐに利用できます

## iPhoneでアプリのように使う(ホーム画面に追加)
1. 公開したURLをiPhoneのSafariで開く
2. 共有ボタン → 「ホーム画面に追加」を選ぶ
3. ホーム画面のアイコンから起動すると、アドレスバーなしのアプリのような画面で使えます
  (この動作にはhttps等でホスティングされたURLとして開く必要があります。ローカルの
  index.htmlファイルを直接開いた場合はこの機能は使えません)

## オフライン利用について
index.html は外部サーバーへの通信を一切行わない単一ファイルです(フォント・ライブラリ等も
すべて内蔵)。一度読み込めば電波が届かない現場でも、ファイルを開いて使い続けられます。
